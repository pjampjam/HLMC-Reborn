# Legacy installer downloads withdrawn

The earlier small native installers were detected by antivirus engines and are no longer distributed. Do not use older installer links or add antivirus exclusions.

Use the current full launcher linked in README.md. It includes its .NET runtime and uses signed automatic updates. It is not Authenticode-signed, so Windows SmartScreen may show Unknown publisher. A local scan does not guarantee every antivirus result.

Microsoft review submissions and diagnostic logs are private. They are not included in this repository or its downloads. Keep antivirus and cloud protection enabled.

[Microsoft guidance for software developers](https://learn.microsoft.com/en-us/defender-xdr/developer-faq)
